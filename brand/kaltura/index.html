Kaltura

Illustration system of 100+ elements for Kaltura, a global leader in enterprise video technology, built as a modular framework

The illustration system is composed of 100+ illustrations, created around a unified logic and separated into different scenes.

Addressing different color palettes and utilizing a distinctive character styling, the illustration system provides a seamless representation of Kaltura’s brand values.

The graphic logic is based on a composition of shapes derived from the Kaltura logo, which have been rearranged to create an entire world
