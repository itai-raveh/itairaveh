# itairaveh.com

Portfolio site. Plain HTML/CSS/JS, no framework.

## Structure
- `site-text.js` — every word on the site, card sizes and order, crop
  focus points, search-engine text (English and Hebrew). Edit this one.
- `site.js` — the site: data (`CATS`, project images and page layouts),
  grids, project pages, lightboxes, routing.
- `site.css` — styling.
- `index.html` — the page shell. Its `<!--seo-->` block is written by
  `tools/build.py`.
- `images/` — artwork, one folder per project. `images/sizes.js` (each
  image's size), the `.md.webp` copies and the Brands cards' padded
  `.card.webp` copies are generated; `images/share/` holds generated share
  pictures.
- `illustration/ brand/ science/ animation/ about/`, `404.html`,
  `sitemap.xml`, `robots.txt` — generated by `tools/build.py`, one page per
  address so search engines can index each project. Don't edit by hand.

## After changing things
One-time setup: `python3 -m venv tools/.venv && tools/.venv/bin/pip install pillow`

- New or changed images → `tools/.venv/bin/python tools/optimize_images.py`
  (turns .png/.jpg into .webp at most 2400px wide, updates references,
  makes the 1200px `.md.webp` copies phones load, rewrites `images/sizes.js`).
  It deletes the .png/.jpg it converts, so keep your originals elsewhere.
  Originals from before the first compression are in
  `Documents/Projects/Website/originals/`.
- Changed `site-text.js` or added a project → `tools/.venv/bin/python tools/build.py`
  (page titles, descriptions, share pictures, sitemap, the Brands cards'
  padded copies).

The site itself works without rebuilding (a new project shows up straight
away); the build only keeps search engines and shared links up to date.

## Addresses
`illustration/`, `illustration/city-symbol/`, `illustration/city-symbol/ymca/`,
`about/`; a project preview over its grid is `illustration/?preview=slug`.
Old `#/…` links are redirected. The site's public address is `site address:`
in `site-text.js` (# general) — change it when moving to a custom domain,
then run the build.

## Local preview
Serve the folder (addresses need a server): `python3 -m http.server 8123`
then open http://localhost:8123/

## Deploy
Push to `main`; GitHub Pages serves it (Settings → Pages). `.nojekyll`
makes Pages serve the files as they are.
